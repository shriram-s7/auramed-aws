====================================================================================================
1. PROJECT OVERVIEW & CLINICAL GOALS
====================================================================================================
AuraMed Healthcare (AuraMed AI) is a specialized, multi-disease clinical decision support system
designed to assist medical professionals (radiologists, cytopathologists, and gynecologists) with
rapid, accurate, and explainable screenings for three critical women's health conditions:

1. Breast Cancer Screening:
   Detects suspicious tissue lesions in digital mammograms and integrates 11 clinical, metabolic,
   and genetic risk factors into an unified diagnostic risk score.

2. Cervical Cancer Cytology Classification:
   Analyzes high-magnification cervical smear microscopy images (.bmp format) to classify cellular
   dysplasia across five distinct histopathological stages using a Vision Transformer.

3. Polycystic Ovary Syndrome (PCOS) Detection:
   Identifies polycystic morphology in pelvic ultrasound scans, generates real-time visual heatmaps
   (Grad-CAM) pinpointing peripheral follicle clusters, and correlates findings with laboratory
   endocrine biomarkers.

The platform runs completely self-contained in a local environment, linking a modern React-based
diagnostic interface with a high-performance Python FastAPI inference server.

3.1 MODULE 1: BREAST CANCER MULTIMODAL LATE-FUSION SYSTEM
----------------------------------------------------------------------------------------------------
Files: `backend setup/breast/inference.py`, `breast_model.pth`, `clinical_model.pkl`

3.1.1 Image Processing Backbone (ResNet-50):
- Model File: `breast_model.pth` (~94.4 MB)
- Base Architecture: 50-layer deep Residual Network (`torchvision.models.resnet50`).
- Classification Head Adaptation:
  The standard 1000-class linear layer is replaced with a single output projection:
    `image_model.fc = nn.Linear(image_model.fc.in_features, 1)`
- Preprocessing Pipeline:
  1. Mammogram image read from raw upload bytes via `PIL.Image.open()` and converted to RGB.
  2. Resized to `(224, 224)` spatial dimensions.
  3. Transformed to PyTorch tensor with normalized float range [0.0, 1.0].
  4. Batch dimension added: tensor shape `(1, 3, 224, 224)`.
- Forward Pass:
  Model evaluates under `torch.no_grad()`. Logit output is activated via Sigmoid:
    `image_score = torch.sigmoid(output).item()`
  Yields a scalar value between 0.0 (benign/normal) and 1.0 (highly suspicious lesion).

3.1.2 Clinical Risk Classifier (Random Forest):
- Model File: `clinical_model.pkl` (~26.1 MB)
- Model Type: `sklearn.ensemble.RandomForestClassifier`
- Enforces strict input validation against 11 clinical features:
  1.  `breast_density`        (Integer 1 to 4: BI-RADS parenchymal density category)
  2.  `age`                   (Integer: Patient chronological age in years)
  3.  `family_history`        (Binary 0/1: Family incidence of breast cancer)
  4.  `hormonal_risk`         (Binary 0/1: Exposure to hormonal therapies or prolonged estrogen)
  5.  `obesity`               (Binary 0/1: Body mass index >= 30)
  6.  `menopause_status`      (Binary 0/1: 0 = Premenopausal, 1 = Postmenopausal)
  7.  `high_risk_age`         (Binary 0/1: Age threshold risk indicator)
  8.  `density_risk`          (Binary 0/1: High tissue density risk flag)
  9.  `genetic_risk_score`    (Float 0.0 - 1.0: Genetic assessment e.g., BRCA proxy)
  10. `lifestyle_risk`        (Float 0.0 - 1.0: Modifiable lifestyle risk factor score)
  11. `combined_risk_index`   (Float 0.0 - 1.0: Composite epidemiological risk score)
- Feature Alignment: Ensures exact ordering matching `clinical_model.feature_names_in_`. Any missing
  column is safely initialized to 0.
- Inference:
    `clinical_score = float(clinical_model.predict_proba(features)[0][1])`

3.1.3 Multimodal Fusion Equation & Risk Stratification:
The system calculates the overall risk through late weighted fusion:
    `final_score = (0.7 * image_score) + (0.3 * clinical_score)`

Clinical Stratification:
- `final_score > 0.60` -> "HIGH RISK OF BREAST CANCER"
- `0.40 < final_score <= 0.60` -> "MODERATE RISK"
- `final_score <= 0.40` -> "LOW RISK"

3.1.4 Rule-Based Clinical Explanation Engine:
The backend synthesizes clear, bulleted diagnostic explanations:
- If `image_score > 0.6`: "Suspicious tissue patterns detected in mammogram."
- If `family_history == 1`: "Family history increases cancer probability."
- If `age > 50`: "Age above 50 increases risk."
- If `breast_density >= 3`: "High breast density detected."
- If `obesity == 1`: "Obesity contributes to hormonal risk."

Medical Recommendations:
- High Risk: Immediate radiologist consultation, diagnostic mammography, biopsy confirmation.
- Moderate Risk: Repeat screening in 2 months, breast ultrasound evaluation, lifestyle risk reduction.
- Low Risk: Routine screening after 2 years, healthy lifestyle maintenance.

3.1.5 Multi-Year Longitudinal Risk Timeline Forecasting:
Projects forward-looking disease progression probabilities for clinical monitoring:
- 6-Month Risk: `min(final_score * 1.10, 1.0)`
- 1-Year Risk:  `min(final_score * 1.25, 1.0)`
- 3-Year Risk:  `min(final_score * 1.50, 1.0)`
Delivered as a structured dictionary to the frontend and rendered as an interactive Recharts curve.

3.2 MODULE 2: CERVICAL CANCER VISION TRANSFORMER (ViT) CLASSIFIER
----------------------------------------------------------------------------------------------------
Files: `backend setup/cervical/inference.py`, `aura_med_cervical_v1.pth`

3.2.1 Deep Learning Architecture (ViT-Base Patch16-224):
- Model File: `aura_med_cervical_v1.pth` (~343.3 MB)
- Library: `timm` (PyTorch Image Models)
- Architecture Identifier: `vit_base_patch16_224`
- Structural Details:
  * Image Resolution: 224 x 224 pixels
  * Patch Size: 16 x 16 pixels (yields 14 x 14 = 196 image patches)
  * Token Embeddings: 196 image tokens + 1 class [CLS] token
  * Embedding Dimension: 768
  * Transformer Layers: 12 self-attention blocks
  * Attention Heads: 12 heads per block
  * Classifier Head: 5-class linear projection (`num_classes=5`)

3.2.2 Microscopic Cytology Preprocessing Pipeline:
- Supported Formats: `.bmp` (native digital Pap smear microscopy format), `.jpeg`, `.png`.
- Preprocessing steps:
  1. Decode image stream into RGB format.
  2. Resize image to `(224, 224)`.
  3. Transform to PyTorch Tensor.
  4. Standard ImageNet channel normalization:
     `mean = [0.485, 0.456, 0.406]`
     `std  = [0.229, 0.224, 0.225]`
  5. Tensor unsqueezing to shape `(1, 3, 224, 224)`.

3.2.3 Five Histopathological Output Classes:
The model computes logits over five cellular categories:
  Index 0: "Dyskeratotic"  -> Severe atypical keratinization (CIN3 / invasive precursor)
  Index 1: "Koilocytotic"   -> HPV-related cytopathic changes with perinuclear halo (CIN1)
  Index 2: "Metaplastic"    -> Squamous metaplasia at the cervical transformation zone (CIN2)
  Index 3: "Parabasal"      -> Immature basal cells (atrophic or deep erosive dysplasia)
  Index 4: "Normal"         -> Healthy, well-differentiated squamous epithelium

Inference Execution:
  1. `outputs = model(input_data)`
  2. `probs = torch.softmax(outputs[0], dim=0)`
  3. `conf, pred = torch.max(probs, 0)`
  4. Returns `prediction: class_names[pred.item()]` and `confidence: float(conf)`.

3.2.4 Bethesda System Clinical Progression Matrix:
The UI automatically matches the prediction against the standard clinical Bethesda staging matrix:
- Normal    -> Very Low Risk -> Routine age-appropriate screening.
- CIN1      -> Low Risk      -> Mild dysplasia; repeat cytology in 12 months.
- CIN2      -> Moderate Risk -> Moderate dysplasia; colposcopy & potential treatment.
- CIN3      -> High Risk     -> Severe dysplasia; immediate excisional biopsy/LEEP.
- Carcinoma -> Critical Risk -> Invasive cancer; referral to gynecologic oncologist.

3.3 MODULE 3: PCOS ULTRASOUND CLASSIFIER & EXPLAINABLE AI (GRAD-CAM)
----------------------------------------------------------------------------------------------------
Files: `backend setup/pcos/inference.py`, `pcos_vision_model.pth`

3.3.1 Customized Neural Backbone (PCOSVisionModel / ResNet-50):
- Model File: `pcos_vision_model.pth` (~94.4 MB)
- Custom Model Definition:
  ```python
  class PCOSVisionModel(nn.Module):
      def __init__(self):
          super(PCOSVisionModel, self).__init__()
          self.resnet = models.resnet50(weights=None)
          num_ftrs = self.resnet.fc.in_features
          self.resnet.fc = nn.Sequential(
              nn.Dropout(0.5),
              nn.Linear(num_ftrs, 2)
          )
      def forward(self, x):
          return self.resnet(x)
  ```
- Binary Classification Output:
  * Index 0: `Healthy` (Normal ovarian morphology)
  * Index 1: `PCOS` (Polycystic ovarian morphology)

3.3.2 Real-Time Grad-CAM Mathematical Mechanics:
To ensure clinical transparency, Grad-CAM (Gradient-Weighted Class Activation Mapping) is executed
on every ultrasound image during inference:
- Target Convolutional Layer: `model.resnet.layer4[-1]` (the last residual block before pooling).
- Hook Registration:
  * Forward Hook records layer activations: `activations.append(act)`
  * Full Backward Hook records backpropagated gradients: `gradients.append(grad)`
- Mathematical Execution:
  1. Model forward pass generates logits: `output = model(img_tensor)`
  2. Winning class identified: `idx = torch.argmax(output).item()`
  3. Backward pass triggered on the winning class:
       `model.zero_grad()`
       `output[0, idx].backward()`
  4. Global Average Pooling over spatial dimensions (H, W) produces neuron importance weights:
       `pooled_grads = torch.mean(gradients[0], dim=[0, 2, 3])`
  5. Weight each feature map channel by its importance weight:
       `acts[:, i, :, :] *= pooled_grads[i]`
  6. Compute mean across channels and apply ReLU:
       `heatmap = torch.mean(acts, dim=1).squeeze().numpy()`
       `heatmap = np.maximum(heatmap, 0)`
       `heatmap /= np.max(heatmap)`

3.3.3 Colormap Generation, Alpha Blending & Base64 Data Streaming:
- Heatmap is resized to `(224, 224)` via OpenCV.
- Mapped to a pseudocolor gradient using `cv2.applyColorMap(..., cv2.COLORMAP_JET)`:
  * Red / Orange highlights regions that contributed strongly to the PCOS diagnosis (e.g. peripheral
    follicular rings or hyperechoic central stroma).
  * Deep Blue represents background non-contributing tissue.
- Blended with the original ultrasound image:
    `overlay = cv2.addWeighted(img_cv, 0.6, heatmap_colored, 0.4, 0)`
- Encoded as a JPEG buffer in-memory and converted to a Base64 string (`encoded_heatmap`), allowing
  the frontend to display the heatmap overlay instantaneously without disk I/O.

3.3.4 Rotterdam Diagnostic Consensus & Endocrine Biomarkers:
The ultrasound evaluation is correlated on the frontend with the Rotterdam Consensus criteria:
- Ovarian volume > 10 ml or >= 12 peripheral follicles (2–9 mm diameter).
- Patient clinical parameters captured:
  * Weight (kg), Height (cm), and calculated Body Mass Index (BMI)
  * Luteinizing Hormone (LH) & Follicle-Stimulating Hormone (FSH)
  * LH/FSH Ratio (a ratio > 2.0 is a hallmark clinical indicator of PCOS)
  * Anti-Müllerian Hormone (AMH - elevated in PCOS patients)
  * Serum Androgen Level (evaluates clinical or biochemical hyperandrogenism)
